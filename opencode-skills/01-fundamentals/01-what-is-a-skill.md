# Что такое Skill

**Время чтения:** 5 мин

## Суть

Skill (навык) — это папка с файлом `SKILL.md`, содержащим инструкции для AI-агента. Skills загружаются по необходимости через механизм автотриггеринга: агент сам решает, когда применить skill, на основе поля `description`.

Skills позволяют изолировать контекст, переиспользовать знания и автоматизировать повторяющиеся задачи, превращая агента в узкоспециализированного исполнителя.

## Основной материал

### Определение

Skill — это директория, содержащая как минимум файл `SKILL.md` с YAML frontmatter и Markdown-инструкциями:

```
skill-name/
├── SKILL.md          # Обязательно: метаданные + инструкции
├── scripts/          # Опционально: исполняемый код
├── references/       # Опционально: документация
└── assets/           # Опционально: шаблоны, ресурсы
```

Единственный обязательный элемент — `SKILL.md`. Его наличие превращает папку в skill.

### Как агент загружает skill

Процесс состоит из трёх этапов (progressive disclosure):

```

Пользователь: "напиши тесты для модуля X"
    │
    ▼
Этап 1 — Discovery: агент читает только name + description
всех доступных skills (~100 токенов на skill)
    │
    ▼
Этап 2 — Activation: совпадение >= 1% → агент
загружает полный SKILL.md (< 5000 токенов)
    │
    ▼
Этап 3 — Execution: агент следует инструкциям,
при необходимости подгружает файлы из scripts/, references/
```

Решение о загрузке принимается по схеме: **описание задачи → match по description → загрузка**. Если точного совпадения нет, но вероятность >= 1% — агент всё равно должен загрузить skill и проверить.

### Зачем нужны skills

| Причина | Что даёт |
|---------|----------|
| **Изоляция контекста** | Инструкции не засоряют основной диалог, живут в файле |
| **Модульность** | Каждый skill отвечает за одну задачу |
| **Переиспользование** | Один skill работает в разных проектах и CLI |
| **Автоматизация** | Агент сам решает, когда применить skill |
| **Дистрибуция** | Skills можно упаковывать и публиковать |

### Skill vs инструкция в диалоге

Обычная инструкция в диалоге:
> "Напиши тесты. Используй pytest. Сначала тест, потом код."

Та же инструкция как skill:
> `skill("test-driven-development")` — агент загружает SKILL.md с полным циклом TDD: red → green → refactor, требования к тестам, правила коммитов.

Разница: skill гарантирует **полноту и воспроизводимость** инструкции, а диалоговая — теряется после сессии.

### Три категории skills

По классификации Anthropic (2026), skills делятся на три типа:

1. **Создание артефактов** — документы, дизайны, код, презентации с единым стилем. Не требуют внешних инструментов.
2. **Автоматизация процессов** — многошаговые процессы с валидацией на каждом этапе.
3. **Усиление MCP-интеграций** — MCP даёт доступ к инструментам (кухня), skill — рецепты их применения.

### Ментальная модель

**Skill = должностная инструкция для агента.**

Как у человека есть должностная инструкция кассира или программиста, так у агента есть skill для тестирования, дебаггинга или код-ревью. Агент "надевает" нужную инструкцию под задачу.

### Где живут skills

```
проект/.opencode/skills/     → локальные, только для проекта
~/.cache/opencode/packages/  → установленные из пакетов
node_modules/superpowers/    → в составе npm-пакета
~/.claude/skills/            → Claude Code (глобальные)
.agents/skills/              → универсальный путь (OpenCode, Gemini, Copilot)
```

## Кейс / пример

Разработчик пишет: "У меня баг — тест не проходит."

Без skill: агент начинает гадать, смотреть логи, менять код наугад.

Со skill `systematic-debugging`: агент загружает SKILL.md, который предписывает:
1. Воспроизвести проблему
2. Сформулировать гипотезу
3. Проверить гипотезу минимальным изменением
4. Зафиксировать результат

Результат — диагностика за 5 минут вместо 30.

## Упражнение

Открой любой `SKILL.md` из установленных пакетов (например, `node_modules/superpowers/skills/brainstorming/SKILL.md`). Найди в нём YAML frontmatter (name, description), инструкции, разделы. Запиши, что делает этот skill — одним предложением.

## Ключевые выводы

- Skill — директория с файлом SKILL.md, загружаемая по необходимости
- YAML frontmatter содержит name (обязательно) и description (обязательно)
- Progressive disclosure: метаданные → инструкции → ресурсы
- Агент загружает skill по совпадению description с задачей (порог — 1%)
- Три категории: артефакты, процессы, усиление MCP
- Skill ≠ диалоговая инструкция: skill воспроизводим и полон, диалог — теряется
- Ментальная модель: skill = должностная инструкция для агента
