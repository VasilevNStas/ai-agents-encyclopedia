# Superpowers: экосистема и пакетный менеджер для skills

**Время чтения:** 7 мин

## Суть

Superpowers — экосистема, позволяющая упаковывать, распространять и устанавливать skills для AI-агентов через стандартную npm-инфраструктуру. Skills поставляются как npm-пакеты, агент находит их автоматически при старте.

## Основной материал

Superpowers использует npm — крупнейший пакетный менеджер в мире — как транспортный слой для skills. Это даёт преимущества: версионирование, зависимости, установка из разных источников, привычные инструменты.

**Установка:**
```bash
npm install superpowers
```

После установки пакет оказывается в `node_modules/`. При старте агент сканирует `node_modules` на предмет пакетов, помеченных флагом `superpowers`.

**Структура пакета:**
```
node_modules/superpowers/
├── package.json        # флаг "superpowers" и путь к skills
├── skills/
│   ├── brainstorming/
│   │   └── SKILL.md
│   ├── systematic-debugging/
│   │   └── SKILL.md
│   └── ...
```

**package.json:**
```json
{
  "name": "superpowers",
  "version": "1.0.0",
  "superpowers": {
    "skills": ["skills/*"]
  },
  "keywords": ["superpowers", "opencode"]
}
```

Флаг `superpowers` сообщает агенту, что этот пакет содержит skills. Поле `skills` указывает глобальный шаблон, по которому искать SKILL.md.

**Установлен vs Доступен.** Установка пакета через npm не означает, что его skills автоматически загрузятся в каждую сессию. Установка = пакет есть в node_modules. Доступность = агент нашёл флаг `superpowers` и зарегистрировал skills. Skill загружается **только** когда пользователь (или агент) вызывает `skill("имя")`.

**Локальные skills.** Помимо node_modules, агент ищет skills в локальных директориях: `.opencode/skills/`, `.claude/skills/`, `.agents/skills/`. Это удобно для проектных skills, которые не нужно публиковать.

## Кейс / пример

Установи пакет superpowers от Obra:
```bash
npm install superpowers
```

После установки открой `node_modules/superpowers/skills/`. Разбери один пакет: какие skills входят, как называются директории, что лежит внутри каждой.

## Ключевые выводы

- Superpowers использует npm как инфраструктуру для распространения skills
- Пакет отмечается флагом `superpowers` в package.json
- Агент сканирует node_modules при старте и регистрирует skills
- Установка пакета не равна автоматической загрузке skill
- Локальные skills можно хранить в `.opencode/skills/` и аналогичных директориях
- Superpowers — не единственный способ, а стандартная библиотека
