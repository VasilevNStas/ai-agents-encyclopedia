# AI Teacher Skills

> Глубокое изучение темы **Skills** в контексте AI-агентов: OpenCode, Superpowers, экосистема. Май 2026. Курс переписан на основе официальной спецификации [agentskills.io](https://agentskills.io/specification).

## Структура курса

```
01-fundamentals/            → база: что такое Skill, progressive disclosure, иерархия (3 файла)
02-anatomy/                 → SKILL.md: YAML frontmatter, spec, валидация (3 файла)
03-mechanics/               → Skill Tool, порог 1%, lifecycle (3 файла)
04-superpowers/             → экосистема, пакеты, дистрибуция (3 файла)
05-writing/                 → написание skills, best practices, tool mapping (3 файла)
06-advanced/                → композиция, цепочки, трюки (3 файла)
07-debugging/               → диагностика проблем с skills (3 файла)
08-testing-security/        → тестирование и безопасность (4 файла)
09-performance/             → влияние на контекст и оптимизация (3 файла)
10-fleet-management/        → CI/CD, мониторинг, управление парком, кросс-агентность (4 файла)
```

Всего: **32 файла** + практические упражнения в каждом.

## Как учиться

Последовательно, модуль за модулем (01 → 10). Каждый модуль содержит:
- теорию с примерами на основе официальной спецификации agentskills.io
- кейсы из реальной практики Superpowers
- упражнения для самопроверки
