# Skill: Lesson Creator

## Когда использовать
- Создание нового урока
- Реструктуризация существующего урока
- Добавление практического задания

## Процесс

1. Определи цель урока (одно предложение)
2. Выдели ключевую идею (спрячь в `> [!quote]`)
3. Разбей на подразделы (N.1, N.2, N.3)
4. Напиши теорию с примерами кода
5. Добавь практическое задание
6. Добавь вопросы для проверки (3-5)
7. Добавь ссылки на соседние уроки

## Структура урока

```markdown
---
created: YYYY-MM-DD
tags: [course/<module>, <topic>]
status: active
---

# Урок N: Название

> [!quote] Ключевая идея
> <одно предложение, ради которого написан урок>

---

## <N.1> <Подраздел>
<теория, объяснение>

```python
# код примера

```

---

## Резюме
```
<визуальная схема main takeaways>
```

---

## Практическое задание
<конкретное задание в OpenCode>

---

## Проверь себя
1. <вопрос>
2. <вопрос>

---

## Ссылки
- [[предыдущий урок]]
- [[следующий урок]]
```

## Правила форматирования

1. Каждый файл начинается с YAML frontmatter
2. Использовать WikiLinks `[[link]]`
3. Код-блоки с указанием языка
4. Callout-блоки для важных заметок:
   ```
   > [!note] — заметка
   > [!warning] — предупреждение
   > [!tip] — совет
   > [!important] — важно
   > [!quote] — ключевая цитата
   ```
5. В конце каждого урока — «Проверь себя» (3-5 вопросов)
6. После каждого блока уроков — практическое задание
7. Ссылки на предыдущий и следующий урок
