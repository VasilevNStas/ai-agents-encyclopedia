# Урок 5: Reflexion — как агент учится на ошибках

> [!quote] Ключевая идея
> Reflexion (Shinn et al., 2023) добавляет в цикл агента **фазу рефлексии**: агент делает → оценивает результат → запоминает урок → применяет в следующих попытках.

---

## Проблема

ReAct и Plan-and-Solve **не учатся на ошибках** в рамках одной задачи. Если агент:

1. Попробовал прочитать несуществующий файл
2. Получил ошибку
3. Попробовал снова — и снова ту же ошибку

— это **цикл без рефлексии**. Агент не делает вывода: «файла нет, надо сначала его найти».

---

## Архитектура Reflexion

```
         ┌──────────────────────────────────────┐
         │              Actor                     │
         │  (LLM, который думает и действует)     │
         └────────┬─────────────────────────────┘
                  │
                  ▼
         ┌──────────────────────────────────────┐
         │           Evaluator                    │
         │  (проверяет: успех или провал?)        │
         └────────┬─────────────────────────────┘
                  │
                  ▼
         ┌──────────────────────────────────────┐
         │         Self-Reflection                │
         │  (что пошло не так? что выучить?)      │
         └────────┬─────────────────────────────┘
                  │
                  ▼
         ┌──────────────────────────────────────┐
         │           Memory                        │
         │  (урок → в контекст для следующих       │
         │   попыток)                              │
         └──────────────────────────────────────┘
```

Четыре компонента:

| Компонент | Роль | Что делает |
|-----------|------|-----------|
| **Actor** | Исполнитель | Думает и действует (ReAct) |
| **Evaluator** | Критик | Оценивает результат: успех / неудача / частично |
| **Self-Reflection** | Аналитик | Пишет «урок»: что пошло не так и почему |
| **Memory** | Хранилище | Сохраняет уроки для следующих попыток |

## Как это выглядит в коде

```python
def reflexion_agent(task: str, max_trials: int = 3):
    """Агент с рефлексией: пробует, оценивает, учится, пробует снова."""

    reflections = []  # накопленные уроки

    for trial in range(max_trials):
        # 1. ACTOR: выполняет задачу с учётом прошлых уроков
        context = build_context(task, reflections)
        result = actor_loop(context)

        # 2. EVALUATOR: оценивает результат
        eval_result = evaluate(task, result)

        if eval_result == "SUCCESS":
            return result

        # 3. SELF-REFLECTION: извлекает урок
        lesson = reflect(task, result, eval_result)

        # 4. Сохраняет урок в память
        reflections.append(lesson)
        print(f"Попытка {trial+1} не удалась. Урок: {lesson}")

    return result  # последняя попытка (даже неудачная)


def reflect(task: str, result: str, evaluation: str) -> str:
    """LLM пишет урок: что именно пошло не так."""

    prompt = f"""
    Задача: {task}
    Что было сделано: {result}
    Оценка: {evaluation}

    Проанализируй ошибку. Ответь в формате:
    УРОК: <что именно было не так>
    ПРИЧИНА: <почему это произошло>
    ИСПРАВЛЕНИЕ: <как избежать в следующий раз>
    """
    return llm.generate(prompt)


def build_context(task: str, reflections: list[str]) -> str:
    """Собирает контекст: задача + все прошлые уроки."""

    context = f"Задача: {task}\n\n"

    if reflections:
        context += "Из прошлых попыток я узнал:\n"
        for r in reflections:
            context += f"- {r}\n"
        context += "\n"

    context += "Начинаю новую попытку. Учитываю уроки.\n"
    return context
```

## Пример из жизни

**Задача:** «Найди функцию `calculate_total` и добавь в неё логирование»

```
ПОПЫТКА 1 (Actor):
  grep("calculate_total") → "not found"
  Думает: "нет такой функции" → FAIL

EVALUATOR: Задача не выполнена. Функция существует, но под другим именем.

SELF-REFLECTION:
  УРОК: функция может называться по-другому
  ПРИЧИНА: искал точное совпадение, не учёл синонимы
  ИСПРАВЛЕНИЕ: искать шире — grep("total") или grep("calc")

ПОПЫТКА 2 (Actor):
  grep("total") → "def compute_total():"
  Читает → добавляет логирование → SUCCESS
```

Без рефлексии агент навсегда застрял бы на «нет такой функции».

---

## Reflexion vs ReAct vs Plan-and-Solve

| Критерий | ReAct | Plan-and-Solve | Reflexion |
|----------|-------|---------------|-----------|
| План | Нет | Есть | Есть (внутри попытки) |
| Рефлексия | Нет | Нет | Есть |
| Обучение | Нет | Нет | Есть (уроки между попытками) |
| Сложность | Низкая | Средняя | Высокая |
| Расход токенов | Низкий | Средний | Высокий (каждая попытка + рефлексия) |
| Когда нужен | Простые задачи | Сложные задачи | Задачи, где ошибка дорого стоит |

## Anti-pattern: бесконечная рефлексия

**Ошибка новичка:** разрешить агенту рефлексировать бесконечно.

```python
# ❌ Anti-pattern
while True:
    result = actor(task)
    lesson = reflect(result)
    reflections.append(lesson)
    # никогда не остановится, если evaluator бажный
```

**Правило архитектора:** у рефлексии должен быть **лимит**:

```python
# ✅ Правильно
MAX_TRIALS = 3
IMPROVEMENT_THRESHOLD = 0.2  # если улучшение < 20% — стоп

for trial in range(MAX_TRIALS):
    result = actor(task, reflections)
    score = evaluate(result)
    
    if trial > 0:
        improvement = (score - prev_score) / prev_score
        if improvement < IMPROVEMENT_THRESHOLD:
            print("Улучшение незначительное — останавливаюсь")
            break
    
    prev_score = score
    reflections.append(reflect(task, result))
```

## Когда Reflexion необходим

1. **Debugging** — агент ищет баг, первая попытка неудачна, нужно переосмыслить
2. **Написание кода** — тесты упали, нужно понять почему и переписать
3. **Исследование** — первый источник ничего не дал, нужно сменить стратегию поиска
4. **Любая задача, где неудача стоит дорого** — лучше потратить токены на рефлексию, чем выдать неверный результат

---

## Резюме

```
Агент без рефлексии:  пробует → ошибка → пробует то же самое → ошибка
Агент с рефлексией:   пробует → ошибка → анализирует → пробует иначе → успех
```

Рефлексия — это **разрыв цикла повторения ошибок**. Она превращает агента из «упрямого исполнителя» в «адаптивного решателя».
