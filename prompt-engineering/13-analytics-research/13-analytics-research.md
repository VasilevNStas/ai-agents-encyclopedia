# Модуль 13: Аналитика и исследования

> [!quote] Ключевая идея
> LLM не считает цифры, но отлично видит паттерны.
> Аналитические промпты — это фреймворки для структурирования
> информации и поиска взаимосвязей.

---

## 1. Анализ данных

### Сводка по данным

```
Ты — аналитик. Проанализируй данные:

{data}

Сделай:
1. **Сводка**: ключевые метрики, тренды, аномалии
2. **Инсайты**: что неочевидно на первый взгляд?
3. **Риски**: на что обратить внимание?
4. **Рекомендации**: что делать на основе данных?

Формат: кратко, без воды, с цифрами.
Если данных недостаточно для вывода — напиши «Требуется дополнительная информация».
```

### Поиск аномалий

```
Данные: {data}

Найди аномалии:
- Выбросы (значения, сильно отличающиеся от нормы)
- Пропуски (отсутствующие данные)
- Несоответствия (логические противоречия)
- Изменения тренда (резкие переломы)

Для каждой аномалии: описание + возможная причина + степень критичности.
```

## 2. Фреймворки анализа

### SWOT

```
Ты — стратегический аналитик.
Проведи SWOT-анализ для {объект_анализа}.

Strengths (внутренние):
- Что мы делаем хорошо?
- Какие у нас уникальные ресурсы?

Weaknesses (внутренние):
- Что можно улучшить?
- Где мы проигрываем конкурентам?

Opportunities (внешние):
- Какие тренды работают на нас?
- Какие новые рынки / технологии открываются?

Threats (внешние):
- Что делают конкуренты?
- Какие регуляторные / рыночные риски?

Формат: таблица с 3-5 пунктами в каждой категории.
В конце — вывод: основная стратегическая рекомендация.
```

### PEST

```
Проведи PEST-анализ для {отрасль / рынок}.

Political:
- Законодательство, регулирование
- Налоговая политика
- Торговые ограничения

Economic:
- Темпы роста рынка
- Инфляция, курсы валют
- Уровень доходов ЦА

Social:
- Демография
- Изменение привычек потребления
- Образовательный уровень

Technological:
- Новые технологии
- Скорость устаревания текущих решений
- R&D в отрасли

По каждому фактору: влияние (высокое/среднее/низкое) + вероятность.
```

### 5 Whys (5 почему)

```
Примени метод «5 почему» для проблемы:

Проблема: {problem}

Почему 1: (ответ LLM)
  Почему 2: (ответ LLM, исходя из Почему 1)
    Почему 3: (ответ LLM, исходя из Почему 2)
      Почему 4: (ответ LLM, исходя из Почему 3)
        Почему 5: (ответ LLM, исходя из Почему 4)

Корневая причина: ...
Рекомендация: ...
```

## 3. Исследование

### Анализ статьи / документа

```
Проанализируй источник:

{text}

Критерии:
1. **Основной тезис** — что автор доказывает?
2. **Аргументация** — какие доводы приводит? Надёжные ли?
3. **Данные** — есть ли цифры, исследования? Какие?
4. **Bias** — что автор умалчивает? Какая у него позиция?
5. **Ограничения** — где аргументация слабая?
6. **Вывод** — согласны или нет? Почему?

Итоговая оценка: надёжность источника (1-10), практическая ценность (1-10).
```

### Сравнение гипотез

```
У меня есть две гипотезы:
Гипотеза А: {hypothesis_a}
Гипотеза Б: {hypothesis_b}

Сравни по критериям:
1. **Объяснительная сила** — какая гипотеза объясняет больше фактов?
2. **Простота** — какая требует меньше допущений? (бритва Оккама)
3. **Предсказательная сила** — какие предсказания делает каждая?
4. **Проверяемость** — как можно проверить каждую?
5. **Свидетельства** — какие факты поддерживают каждую?

Вывод: какая гипотеза предпочтительнее и почему.
```

### Бенчмарк

```
Сравни {product_a} и {product_b} по параметрам:

| Параметр | {product_a} | {product_b} |
|----------|-------------|-------------|
| Цена | | |
| Функции | | |
| UX | | |
| Поддержка | | |
| Интеграции | | |
| Ограничения | | |

Источники данных: {sources}
Дополнительно: отзывы пользователей, рейтинги, тенденции.
Вывод: какой продукт / когда выбирать?
```

## 4. Систематизация

### Классификация

```
Классифицируй следующие элементы по категориям:
{items}

Категории: {categories}
Или: предложи свои категории на основе данных.

Для каждого элемента: категория + обоснование (почему туда).
```

### Причинно-следственная диаграмма

```
Построй причинно-следственную связь для:

Событие: {event}

Цепочка:
Причина → Событие → Следствие → Последствие

Для каждого узла: что именно произошло, кто участники,
какова вероятность связи (высокая / средняя / низкая).
```

## 5. Промпты-фреймворки

### Decision Matrix

```
Помоги принять решение.

Варианты: {options}
Критерии: {criteria}
Вес каждого критерия (1-5): {weights}

Построй матрицу решений:
| Критерий (вес) | Вариант А | Вариант Б | Вариант В |
|----------------|-----------|-----------|-----------|
| Критерий 1 (5) | 3/15 | 5/25 | 4/20 |
| Критерий 2 (3) | ... | ... | ... |
| **Итого** | **сумма** | **сумма** | **сумма** |

Рекомендация: вариант с наибольшей суммой.
```

### Cost-Benefit Analysis

```
Проведи анализ затрат и выгод для:

Решение: {decision}

Затраты:
- Финансовые (прямые/косвенные)
- Временные
- Ресурсные (люди, технологии)
- Риски (что может пойти не так)

Выгоды:
- Финансовые
- Стратегические
- Конкурентные преимущества
- Обучение / опыт

Окупаемость: оценка срока (мес/лет)
Вердикт: делать / не делать / отложить
```
