# Модуль 3: Chain-of-Thought

> [!quote] Ключевая идея
> CoT — единственный способ заставить LLM «думать», а не просто
> угадывать следующий токен. Но работает он только для задач,
> где есть логика.

---

## 1. Zero-shot CoT

Просто добавь в контекст фразу:

```
Давай подумаем шаг за шагом.
```

**До CoT:**
```
Q: У Маши 3 яблока, у Пети на 2 больше. Сколько всего яблок?
A: 5
```

**После CoT:**
```
Q: У Маши 3 яблока, у Пети на 2 больше. Сколько всего яблок?
A: У Маши 3 яблока. У Пети на 2 больше, значит 3+2=5. Всего 3+5=8. Ответ: 8.
```

**Почему работает:** LLM «вовлекается» в процесс генерации промежуточных шагов, что снижает вероятность ошибки.

---

## 2. Few-shot CoT

Дай пример рассуждения + ответа, потом задачу.

```
Q: У Маши 5 конфет, у Пети в 2 раза больше. Сколько всего?
A: У Пети 5×2=10 конфет. Всего 5+10=15. Ответ: 15.

Q: У Васи 3 книги, у Анны на 4 больше, у Димы — половина от Анны. Сколько книг у Димы?
A:
```

## 3. Self-Consistency

Сгенерируй несколько трасс рассуждения (temperature > 0), потом выбери самый частый ответ.

```
Трасса 1: 3+4=7, 7/2=3.5 → 3.5
Трасса 2: (3+4)/2=3.5 → 3.5
Трасса 3: 3+4=7, половина=4 → 4 (ошибка)
```

**Голосование:** "3.5" победила (2 из 3).

**Когда использовать:** Задачи с одним правильным ответом (математика, логика). Не работает для творческих задач.

---

## 4. Tree-of-Thoughts

Ветвление рассуждений — LLM рассматривает несколько путей одновременно.

```
Шаг 1: Возможные подходы: A, B, C
  ├── A → результат X
  ├── B → результат Y  
  └── C → результат Z

Шаг 2: Оцениваем X, Y, Z — выбираем лучший путь
Шаг 3: Продолжаем по выбранному пути
```

**Когда:** Сложные задачи с несколькими возможными решениями (планирование, архитектура).

---

## 5. Обратный CoT (Reverse CoT)

LLM сначала генерирует ответ, а потом объясняет, как к нему пришла.

```
Q: Сколько будет 24 × 7?
A: 168. Рассуждение: 20 × 7 = 140, 4 × 7 = 28, 140 + 28 = 168.
```

**Когда:** Скорость важнее прозрачности. У нас уже есть ответ — хотим верифицировать логику.

**Чем отличается от обычного CoT:** Обычный CoT генерирует рассуждение ДО ответа. Обратный — ПОСЛЕ. Это меняет поведение: LLM подстраивает объяснение под ответ, а не наоборот. Полезно для дебага, но может «объяснять» неверный ответ убедительно.

---

## 6. Plan-and-Solve

Улучшение CoT: сначала составить план, потом выполнять.

```
Q: Клиент хочет узнать статус заказа №12345.
Он написал в поддержку вчера, но ответа нет.

План:
1. Найти заказ в БД по номеру
2. Проверить статус
3. Проверить историю обращений
4. Сформулировать ответ

Шаг 1: поиск заказа...
Шаг 2: статус: «в обработке»...
```

**Когда:** Задачи, где важна последовательность шагов и легко потеряться.

---

## 7. Re-reading (перечитывание)

Перед ответом LLM перечитывает вопрос — снижает вероятность, что она пропустит важную деталь.

```
Вопрос: На складе 15 ящиков по 8 кг и 10 ящиков по 12 кг.
Сколько всего кг на складе?
(Перечитай вопрос перед ответом.)
```

**Когда:** Длинные или многосоставные вопросы, где легко упустить часть данных.

---

## 8. Вред CoT

CoT — не серебряная пуля. В некоторых случаях он ухудшает результат:

| Ситуация | Почему CoT вредит | Что делать |
|----------|-------------------|------------|
| Простой фактологический вопрос | «Рассуждение» может увести от прямого ответа | Ответь сразу |
| Задача не имеет логической структуры | LLM придумает ложную логику | Не используй CoT |
| Форматирование / перевод | CoT добавляет шум | Простой промт лучше |
| Эмоциональный / творческий ответ | CoT делает ответ сухим и механическим | Temperature + без CoT |
| Короткий вопрос («да/нет») | CoT тратит токены на ненужные шаги | Ответь без CoT |

**Правило:** Если человек отвечает мгновенно — CoT не нужен. Если человеку нужно подумать — CoT поможет.

| Помогает | Не помогает |
|----------|-------------|
| Математика | Простые факты |
| Логические цепочки | Творчество |
| Многошаговые инструкции | «Ответь одним словом» |
| Планирование | Эмоциональный тон |
| Отладка | Форматирование |

**Правило:** Если человеку нужно подумать — CoT поможет. Если человек отвечает мгновенно — CoT не нужен.

## Практика

> [!tip] Задание
> Реши задачу с CoT и без. Сравни.

**Задача:** Если три кошки ловят трёх мышей за три минуты, сколько времени нужно одной кошке, чтобы поймать одну мышь?

**Сделай:**
1. Ответь без CoT (сразу)
2. Ответь с CoT (шаг за шагом)
3. Сравни ответы
4. Какой правильный?
