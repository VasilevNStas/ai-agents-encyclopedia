# Модуль 12: Креативные промпты

> [!quote] Ключевая идея
> Креативность LLM — это не магия, а consequence random sampling
> с правильной инструкцией. Temperature управляет шириной поиска,
> промпт — его направлением.

---

## 1. Температура и креативность

| Temperature | Эффект | Для каких задач |
|-------------|--------|-----------------|
| 0.0–0.3 | Консервативно, предсказуемо | Брифы, формальные тексты |
| 0.4–0.6 | Сбалансированная креативность | Статьи, посты, сценарии |
| 0.7–0.9 | Высокая вариативность | Идеи, названия, мозговой штурм |
| 1.0+ | Хаотично, неожиданно | Эксперименты, поиск нестандартных решений |

**Принцип:** Temperature определяет ширину выборки токенов. Чем выше — тем менее вероятные слова попадают в ответ. Для креатива это плюс, для точности — минус.

## 2. Генерация идей (Ideation)

### Мозговой штурм (Brainstorming)

```
Ты — фасилитатор брейншторма.
Задача: сгенерировать 20 идей для {тема}.

Правила:
- Количество важнее качества (сначала 20, потом отсев)
- Без самоцензуры (записывай даже «глупые» идеи)
- Комбинируй: соединяй несовместимые концепции
- Формат: каждая идея — 1 предложение
- Нумеруй от 1 до 20
```

### Идеи на стыке (Cross-domain)

```
Соедини две несвязанные области:
Область А: {domain_a}
Область Б: {domain_b}

Сгенерируй 10 идей на стыке.
Для каждой: краткое описание + почему это может сработать.
```

### Улучшение идеи (Idea Amplifier)

```
У тебя есть идея: {idea}
Усиль её:

1. Что можно добавить? (функции, детали)
2. Что можно убрать? (минимализм)
3. Что можно заменить? (альтернативы)
4. Что можно перевернуть? (противоположный подход)
5. С кем можно объединить? (партнёрства)
```

## 3. Сторителлинг

### Сюжет по структуре

```
Напиши короткий рассказ по структуре трёхактной драмы:

Акт 1 — Завязка (25%):
- Кто герой? Чем занимается? Что хочет?
- Что нарушает привычный порядок?

Акт 2 — Конфликт (50%):
- Какие препятствия встречает?
- Кто помогает? Кто мешает?
- Кульминация: момент выбора

Акт 3 — Развязка (25%):
- Как разрешается конфликт?
- Чем история заканчивается?
- Как изменился герой?

Жанр: {genre}
Персонаж: {character}
Сеттинг: {setting}
```

### Сценарий диалога

```
Напиши диалог между двумя персонажами:

Персонаж А: {person_a} — {характеристика}
Персонаж Б: {person_b} — {характеристика}

Ситуация: {situation}
Тон: {tone} (юмористический, драматический, деловой)
Формат: Имя: реплика

Длина: 10-15 реплик.
Каждая реплика должна продвигать сюжет или раскрывать характер.
```

### Адаптация стиля

```
Напиши текст на тему {topic} в стиле:

Вариант А: официально-деловой (отчёт для руководства)
Вариант Б: научно-популярный (статья для журнала)
Вариант В: разговорный (пост в соцсетях)
Вариант Г: художественный (рассказ с метафорами)
```

## 4. Контент-план

```
Ты — контент-мейкер. Составь контент-план на {период}.

Тематика: {topic}
Целевая аудитория: {audience}
Каналы: {channels}
Цель: {goal}

Формат таблицы:
| Дата | Формат | Заголовок | Ключевое сообщение | CTA |
|------|--------|-----------|-------------------|-----|

Требования:
- Разнообразие форматов (статья, видео, инфографика, пост)
- Релевантность аудитории
- Измеримые цели для каждого поста
```

---

## 5. Метафоры и аналогии

```
Объясни сложную концепцию {concept} через аналогию.

Требования:
- Аудитория: {audience} (возраст, уровень знаний)
- Используй бытовой пример из жизни
- Сначала аналогия, потом прямое объяснение
- Проверь: аналогия не вводит в заблуждение?

Пример структуры:
1. Аналогия: «Это как...»
2. Прямое объяснение: «На самом деле...»  
3. Связь: «Разница в том, что...»
4. Проверка: «Понятно ли? Хочешь, приведу другой пример?»
```

## 6. Параметры для креативных задач

| Параметр | Для креатива | Для точности |
|----------|-------------|--------------|
| Temperature | 0.7–0.9 | 0.0–0.3 |
| Top-p | 0.9–0.95 | 0.1–0.3 |
| Max tokens | Больше (дайте развернуться) | Минимум (только суть) |
| Few-shot | 0–1 пример (не ограничивать) | 1–3 примера |

**На практике:** для генерации идей начни с temp=0.8. Если результат слишком хаотичный — снижай до 0.6. Если слишком скучный — повышай до 0.9.

## Практика

> [!tip] Задание
> 1. Сгенерируй 10 идей для своего текущего проекта (любая тема)
> 2. Отбери 3 лучшие — и усиль каждую через Idea Amplifier
> 3. Напиши короткий рассказ (300 слов) с тремя актами
> 4. Объясни через аналогию: blockchain, LLM или квантовые вычисления — ребёнку 10 лет
> 5. Составь контент-план на неделю для своего Telegram-канала (если нет — вымышленного)
