# Модуль 11: Работа с текстом

> [!quote] Ключевая идея
> LLM — симулятор документов. Работа с текстом — её родная стихия.
> Главное — правильно сформулировать, что именно нужно сделать.

---

## 1. Стратегии для разных объёмов

| Объём | Стратегия | Пример |
|-------|-----------|--------|
| **Короткий** (< 500 токенов) | Всё в один промт | Письмо, пост, описание |
| **Средний** (500-4000) | Чанк + инструкция отдельно | Статья, раздел документации |
| **Длинный** (> 4000) | Разбить на части → обработать → собрать | Книга, большой отчёт |

**Правило:** LLM best-эффективна на текстах до 2000-3000 токенов. Дальше качество падает — точность деталей, следование инструкциям в конце контекста.

## 2. Суммирование (Summarization)

### Разные уровни детализации

```
Уровень 1 — заголовок (10 токенов):
О чём этот текст? Ответь одним предложением.

Уровень 2 — абзац (100 токенов):
Краткое содержание: ключевые факты.

Уровень 3 — конспект (500 токенов):
Структурированный пересказ с сохранением
аргументации и примеров.

Уровень 4 — executive summary:
Для руководителя: проблема, решение, результаты,
рекомендации.
```

### Prompt-фреймворк для суммаризации

```
Ты — аналитик. Суммируй текст ниже.

Формат:
- Основная идея (1 предложение)
- Ключевые тезисы (3-5 пунктов)
- Важные детали (1-2 пункта, опционально)
- Источники и контекст (если применимо)

Не добавляй собственных интерпретаций.
Только то, что есть в тексте.

Текст: {text}
```

## 3. Извлечение информации (Extraction)

### Структурированное извлечение

```
Извлеки из текста структурированные данные.
Верни в JSON:

{
  "date": "дата события или null",
  "people": ["имена людей"],
  "locations": ["географические названия"],
  "organizations": ["названия компаний/организаций"],
  "key_numbers": [{"value": число, "context": "что это"}],
  "action_items": ["что нужно сделать"]
}

Текст: {text}
```

### Q&A по документу

```
Ты отвечаешь на вопросы по документу.
Используй ТОЛЬКО информацию из документа.
Если ответа нет — скажи «Нет в документе».
Цитируй поддержку: [section:строка]

Документ:
{document}

Вопросы:
{questions}
```

## 4. Сравнение (Comparison)

```
Сравни два текста по параметрам:
1. Основные темы — совпадают или различаются?
2. Ключевые факты — какие уникальные для каждого?
3. Тон и целевая аудитория — одинаковые?
4. Выводы — согласуются или противоречат?

Текст А: {text_a}
Текст Б: {text_b}
```

## 5. Редактура (Editing)

### Исправление

```
Ты — редактор. Исправь текст:
- Грамматические ошибки
- Стилистические погрешности
- Нелогичные переходы
- Тавтологию

Сохрани тон и стиль автора.
Не переписывай — только правки.

Формат:
- Изменение: было → стало (причина)
```

### Адаптация под аудиторию

```
Перепиши текст для другой аудитории:

Исходный: {text}
Исходная аудитория: {from_audience}
Целевая аудитория: {to_audience}

Требования:
- Сохрани все ключевые факты
- Адаптируй лексику
- Измени сложность объяснений
- Добавь/убери примеры под аудиторию
```

## 6. Перевод

### Базовый промт

```
Ты — профессиональный переводчик.
Специализация: {domain} ({from_lang} → {to_lang}).

Требования:
- Точность терминологии
- Сохранение структуры (списки, заголовки)
- Адаптация примеров под культуру {to_lang}
- Естественное звучание на языке перевода

Текст: {text}
```

### Мультиязычный промт (перевод + адаптация)

```
Переведи и адаптируй текст для международной аудитории.
Удали культурные отсылки, непонятные за пределами {country}.
Замени на нейтральные или универсальные аналоги.

Оригинал: {text}
→ Переведено и адаптировано:
```

## 7. Chunking для больших текстов

Если текст не влезает в контекст:

```python
def chunk_text(text, max_tokens=2000):
    """Простое разбиение текста на части."""
    paragraphs = text.split('\n\n')
    chunks = []
    current = []
    current_len = 0
    for p in paragraphs:
        p_len = len(p.split())  # грубая оценка
        if current_len + p_len > max_tokens:
            chunks.append('\n\n'.join(current))
            current = [p]
            current_len = p_len
        else:
            current.append(p)
            current_len += p_len
    if current:
        chunks.append('\n\n'.join(current))
    return chunks

# Обработка: просуммировать каждый чанк → собрать
```
