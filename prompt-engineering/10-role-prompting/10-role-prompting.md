# Модуль 10: Role Prompting

> [!quote] Ключевая идея
> Один промпт — одна роль. Смени роль — смени поведение, тон, глубину.
> Role Prompting позволяет превратить LLM из «болтуна» в эксперта любой профессии.

---

## 1. Что такое Role Prompting

Роль задаёт **рамку восприятия** для LLM — тон, лексику, глубину, приоритеты.

```
# Без роли:
«Напиши письмо клиенту»

# С ролью:
Ты — менеджер поддержки интернет-магазина.
Клиент недоволен задержкой доставки.
Напиши письмо с извинениями и компенсацией.
```

Роль — это не маскарад. Это **фильтр внимания**: LLM выбирает, какая информация релевантна, а какая — нет, исходя из роли.

---

## 2. Паттерны ролей

### Expert Role

LLM выступает как эксперт с конкретным опытом и ограничениями.

```
Ты — юрист с 10-летним опытом в договорном праве.
Специализация: РФ, ГК РФ статьи 307-453.
Отвечай строго в рамках законодательства РФ.
Если не уверен — напиши «Требуется консультация профильного юриста».
```

**Когда:** Задачи, где важны точность и рамки компетенции.

### Persona Cascade

Цепочка ролей для одной задачи — каждая следующая уточняет предыдущую.

```
Ты — опытный маркетолог.
Параметры: B2B SaaS, корпоративные клиенты, рынок РФ.
Стиль: деловой, без воды, с цифрами.
А теперь напиши пост для LinkedIn о нашем новом продукте.
```

**Когда:** Нужна не просто роль, а конкретный угол зрения.

### Multi-perspective

Одна задача — несколько ролей последовательно.

```
Задача: оценить идею мобильного приложения для доставки еды.

1. Как предприниматель: оцени рынок, бюджет, окупаемость
2. Как пользователь: удобно ли пользоваться, что бесит?
3. Как разработчик: какие технологии, сколько времени на MVP?
4. Как инвестор: да/нет, почему?

Синтезируй выводы в один ответ: сводка по 4 углам.
```

**Когда:** Нужно всесторонне оценить ситуацию.

### Adversarial (состязательный)

Две роли, которые спорят друг с другом.

```
Напиши диалог:
- Оптимист: доказывает, что запуск стартапа сейчас — идеальное время
- Пессимист: доказывает, что стартап провалится

В конце — твой вывод как аналитика.
```

**Когда:** Нужно увидеть обе стороны и взвешенное решение.

## 3. Роли для разных сфер

### Маркетинг и копирайтинг

```
Ты — копирайтер экспертного уровня.
Задача: написать лендинг для курса по AI-агентам.
Целевая аудитория: IT-директора, 35-50 лет.
Тон: деловой, без «хайпа», с конкретными цифрами.
Формат: заголовок → подзаголовок → 3 преимущества → CTA.
```

### Аналитика и исследования

```
Ты — бизнес-аналитик.
Данные: {csv}
Сделай:
1. Сводную статистику по ключевым метрикам
2. Топ-3 инсайта
3. Рекомендации на основе данных
Формат: краткий отчёт с ключевыми выводами.
```

### Юриспруденция

```
Ты — юрист. Проанализируй договор на предмет рисков:
1. Явные риски (нарушение закона)
2. Скрытые риски (двусмысленные формулировки)
3. Рекомендации по изменению

Договор: {text}
```

### Преподавание и тьюторство

```
Ты — репетитор по математике для 7 класса.
Объясни теорему Пифагора так, чтобы было понятно.
Используй аналогии из жизни.
После объяснения — задай 3 вопроса для проверки понимания.
Если ученик ошибся — не давай ответ, а задай наводящий вопрос.
```

### Перевод и локализация

```
Ты — профессиональный переводчик.
Специализация: технический английский → русский.
Сохрани терминологию, адаптируй примеры под российский контекст.
Переведи: {text}
```

### Исследования

```
Ты — научный исследователь.
Проанализируй статью по критериям:
- Проблема / гипотеза
- Методология
- Результаты
- Ограничения
- Выводы
Оцени качество: надёжность выводов, bias, reproducibility.
```

## 4. Правила хорошего Role Prompting

| Правило | Плохо | Хорошо |
|---------|-------|--------|
| **Конкретная роль** | «Будь профессионалом» | «Ты — юрист по договорному праву, РФ» |
| **Рамки компетенции** | (нет) | «Отвечай только в рамках своей компетенции» |
| **Формат под роль** | «Ответь кратко» | «Ответь в формате: заключение / риски / рекомендации» |
| **Guardrails для роли** | (нет) | «Не давай медицинских советов — ты не врач» |
| **Да/Нет для роли** | (нет) | «Если не уверен — скажи "Требуется консультация"» |

## 5. Антипаттерны Role Prompting

| Антипаттерн | Проблема | Решение |
|-------------|----------|---------|
| Сверхроль | «Ты — эксперт во всём» | Одна задача — одна роль |
| Противоречивая роль | «Ты — строгий, но дружелюбный» | Однородный тон |
| Роль без контекста | «Ты — врач» (без специализации) | Добавь рамки |
| Много ролей сразу | «Ты — маркетолог, юрист и разработчик» | Раздели на вызовы |
| Роль без guardrails | LLM выходит за рамки | Добавь ограничения |

## Практика

> [!tip] Задание
> Возьми одну реальную задачу из своей работы и примени к ней 3 разных роли.

**Задача:** (выбери свою)
- Написать письмо / пост / отчёт
- Проанализировать данные / ситуацию
- Объяснить концепцию кому-то

**Сделай:**
1. Напиши промт без роли — что получилось?
2. Добавь конкретную роль — что изменилось?
3. Попробуй другую роль — результат другой?
4. Какая роль дала лучший результат? Почему?
