# SWOT-анализ через промптинг

> Production-промт для стратегического анализа. Соответствует модулям 2 (анатомия промпта) и 13 (аналитика).

## Промт

```markdown
Ты — стратегический аналитик с 15-летним опытом в консалтинге.
Специализация: рыночный анализ, конкурентная разведка, стратегическое планирование.
Ты работал с Bain & Company, McKinsey и BCG.

## Контекст
Мы анализируем компанию / проект / продукт: {название_объекта}
Краткое описание: {опиши_объект_в_2-3_предложениях}
Рынок / индустрия: {рынок}

## Задача
Проведи полный SWOT-анализ по следующей структуре.

## Инструкция

1. **Strengths (сильные стороны)** — внутренние факторы, которые дают преимущество
   — Укажи 3-5 пунктов
   — Для каждого — почему это сила именно на этом рынке

2. **Weaknesses (слабые стороны)** — внутренние ограничения
   — Укажи 3-5 пунктов
   — Для каждого — как это проявляется в работе

3. **Opportunities (возможности)** — внешние факторы, которые можно использовать
   — Укажи 3-5 пунктов
   — Для каждого — конкретный сценарий реализации

4. **Threats (угрозы)** — внешние риски
   — Укажи 3-5 пунктов
   — Для каждого — вероятность (низкая/средняя/высокая)

5. **Стратегические выводы**
   — Какие сильные стороны помогут использовать возможности?
   — Какие слабости делают уязвимыми перед угрозами?
   — Топ-3 действия на ближайшие 3 месяца

## Формат вывода

```json
{
  "swot": {
    "strengths": [
      {"item": "…", "rationale": "…"}
    ],
    "weaknesses": [
      {"item": "…", "rationale": "…"}
    ],
    "opportunities": [
      {"item": "…", "scenario": "…"}
    ],
    "threats": [
      {"item": "…", "probability": "…"}
    ]
  },
  "strategy": {
    "strength_opportunity": "…",
    "weakness_threat": "…",
    "top_actions": ["…", "…", "…"]
  }
}
```

### Guardrails
- Все утверждения должны быть основаны на фактах из описания
- Если не хватает данных — укажи предположение с пометкой [ASSUMPTION]
- Не выдумывай цифры и статистику
- Если объект анализа — ты сам (как специалист), сохраняй объективность
```

## Разбор элементов

| Элемент | Присутствует | Критичность |
|---------|:----------:|:----------:|
| **A: Persona** | «аналитик с 15-летним опытом … Bain, McKinsey» | ★★★ |
| **B: Context** | название, описание, рынок — 3 переменные | ★★★ |
| **C: Task** | «проведи SWOT-анализ» | ★★★ |
| **D: Instruction** | 5 шагов с детализацией каждого | ★★★ |
| **E: Format** | JSON-схема вывода | ★★★ |
| **F: Example** | ❌ (нет few-shot) | ★★☆ |
| **G: Guardrails** | ограничения + [ASSUMPTION] | ★★★ |
| **H: CoT-trigger** | неявно (структура по шагам) | ★★☆ |
