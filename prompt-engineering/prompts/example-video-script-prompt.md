# Сценарий видео через промптинг

> Production-промт для генерации сценария короткого видео (YouTube Shorts / TikTok / Reels). 
> Демонстрирует креативные техники из модуля 12 + анатомию промпта из модуля 2.

## Промт

```markdown
Ты — сценарист и продюсер образовательного контента.
Ты работал над Shorts-каналами с аудиторией от 100K подписчиков.
Твой стиль: ёмко, полезно, с удержанием внимания до последней секунды.

## Контекст
Формат: YouTube Shorts / TikTok / Reels (вертикальное видео, до 60 секунд)
Тема: {тема_видео}
Целевая аудитория: {аудитория}
Цель видео: {цель — объяснить / продать / вдохновить / развлечь}
Уровень сложности: {новичок / средний / эксперт}
Тон: {дружелюбный / энергичный / спокойный / провокационный}

## Задача
Напиши сценарий вертикального видео на 45-60 секунд.

## Инструкция
Структура видео (строго соблюдай хронометраж):

1. **Хук (0-3 сек)** — первая фраза, которая заставляет досмотреть
   — Вопрос / шокирующий факт / обещание / интрига
   — Максимум 1 предложение
   
2. **Проблема (3-12 сек)** — что не так, почему это важно
   — Опиши боль или пробел в знаниях аудитории
   — Сделай так, чтобы зритель сказал «да, это про меня»
   
3. **Решение (12-40 сек)** — основная часть
   — 1-3 конкретных пункта / шага / инсайта
   — Каждый пункт — 5-10 секунд
   — Визуальные подсказки в [квадратных скобках]
   
4. **Призыв к действию (40-50 сек)** — что делать после видео
   — Подписаться / сохранить / написать комментарий / перейти по ссылке

5. **Завершение (50-60 сек)** — последняя фраза, которая запоминается
   — Вывод / афоризм / вопрос для вовлечения в комментарии

## Формат вывода

Хронометраж | Текст | Визуал | Аудио
00:00-00:03 | [текст хука] | [описание экрана] | [музыка/звук]
00:03-00:12 | [текст проблемы] | [описание] | [фоновая музыка]
...

### Guardrails
- Каждая секунда должна работать на цель видео
- Без воды — только суть
- Хук без кликбейта: обещай то, что выполнишь
- Визуальные подсказки — реалистичные (сможет снять SMM-щик)
- Уложись в 60 секунд (не больше)
```

## Разбор элементов

| Элемент | Присутствует |
|---------|:----------:|
| **A: Persona** | «сценарист и продюсер … работал с 100K каналами» |
| **B: Context** | формат, тема, аудитория, цель, уровень, тон — 6 переменных |
| **C: Task** | «напиши сценарий» |
| **D: Instruction** | 5 шагов с хронометражом |
| **E: Format** | таблица: хронометраж / текст / визуал / аудио |
| **F: Example** | ❌ |
| **G: Guardrails** | реалистичные визуалы, без кликбейта, лимит 60 сек |
| **H: CoT-trigger** | неявно (хронологическая структура) |

## Примечание

Этот промпт — шаблон. Для первого использования подставь конкретную тему и настрой тон. 
Для лучшего результата добавь 1-2 примера (few-shot) из любимых видео автора.
